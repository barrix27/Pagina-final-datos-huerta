# Pagina-final-datos-huerta

Para poder iniciar el codigo se tiene que pegar esta URL en le navegador "http://127.0.0.1/Carpeta generica propia/index.html".

El dashboard.php tiene como funcion registrar los datos obtenidos a base de tablas y otras graficos.

El menu.php es el menu de la pagina.

El index.html es el menu secundario de la pagina que sirve como concentrador de opciones para el usuario.

El insertar.php es el alta de ususarios.

El mostrar.php permite la edicion y eliminacion de usuarios.


Los datos para Xammp y el phpMyAdmin son los siguientes

Base de datos: huerta_db
  Tabla: usuarios
    Datos de la tabla:  id(a.i), INT(255)
                        nombre,  varchar(255)
                        email,  varchar(255)
                        password,  varchar(255)
